# Práctica 18: Modal & Bottom Sheet

Aplicación móvil elaborada con Expo y React Native para demostrar el uso del componente nativo `Modal` en dos presentaciones:

- Modal centrado con animación `fade`.
- Bottom Sheet con animación `slide` desde la parte inferior.
- Cierre mediante botón, fondo oscuro o botón Atrás de Android.

## Ejecutar

```bash
npm install
npm start
```
